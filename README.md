#Library Management System

A C++ console application for managing books,members,and borrowing records.

##Features
-Add and remove books
-Add and remove members
-Borrow books
-Return books
-View all borrowings
-Save and load library data from file
-Interactive menu system

##Technologies
-C++
-Object-Oriented Programming (OOP)
-STL (map,vector)
-File handling
-Git & GitHub
